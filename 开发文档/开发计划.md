### Phase 2：浏览器接管与在线微简历 DOM 采集【⏳ 下一步】

将 Boss 直聘网页上的真实元素转化为符合 `schemas.py` 规范的标准 JSON。

- **对应业务环节**：推荐牛人列表加载 $\rightarrow$ 一级漏斗秒筛 $\rightarrow$ 二级漏斗点开弹窗抓取。
- **具体开发任务**：
  1. **Playwright CDP 免登录接管模块**：
     - 编写启动脚本，通过 Chrome 调试协议（`connect_over_cdp("http://localhost:9222")`）无缝接管你日常已登录 Boss 直聘的本地 Chrome 浏览器，绕过登录验证与环境指纹检测。
  2. **一级漏斗秒筛器（外层卡片）**：
     - 读取列表卡片 DOM，若主按钮为“继续沟通”则秒跳过；
     - 提取外层学历、年限、薪资，结合本地 SQLite 去重库秒筛，不符合硬条件的人绝不触发点击。
  3. **二级微简历弹窗解析器（生成 `ResumeData`）**：
     - 模拟真人随机停顿（2.5s~5.5s）点击符合条件的卡片；
     - 精准抓取弹窗中的：顶部个人优势、带胶囊标签的工作经历、项目经历、含毕设描述的教育经历、专业技能，并提取 DOM 的 `data-lid` 与底层的 `encryptGeekId`。
     - 将解析出的对象写入本地 JSON 归档（实现 `boss-hr-agent-toolkit` 风格存储）。

### Phase 3：A+B 混合寻址执行与风控熔断体系【⏳ 下一步】

打通“打招呼动作的触发”与“高频自动化运行的安全保护”。

- **对应业务环节**：高分直发 $\rightarrow$ 待核验暂存 $\rightarrow$ 审核批准后批量回溯发送 $\rightarrow$ 风控刹车。
- **具体开发任务**：
  1. **A+B 混合寻址打招呼执行器**：
     - **高分直发分支**：若开启自动打招呼且得分 $\ge 82$，在弹窗内直接点击“立即沟通”按钮，发送 Boss 后台默认招呼语。
     - **待核验批准分支（核心难点）**：针对通过审核的候选人，**优先执行方案 A（DOM 回溯）**，通过页面卡片的 `data-lid` 平滑滚动并点击按钮；若页面发生虚拟滚动节点回收，**兜底执行方案 B（加密 ID 寻址）**，重新拉起弹窗完成点击。
  2. **双配额与风控熔断机制**：
     - **单批次上限计数器**：单次运行扫描/处理满 **30 人**（支持动态修改），脚本自动挂起，通知 HR 审核。
     - **单日上限保护锁**：每日累计打招呼满 **100 人**，硬编码锁死发送动作，防止账号受限。
     - **滑块验证码拦截器**：监听 DOM 滑块弹窗，捕获后发出系统通知并暂停脚本，人工滑过后支持一键继续。
  3. **本地状态持久化（SQLite）**：
     - 记录已处理候选人的 `candidate_key`、最终得分、发送状态及时间戳，作为去重判断源。

### Phase 4：HR 审核看板与配置控制台【⏳ 待开发】

- **对应业务环节**：HR 3秒速读核验 $\rightarrow$ 勾选批量发送 $\rightarrow$ 调整筛选标准。
- **具体开发任务**：
  1. **轻量后端服务（FastAPI）**：
     - 挂载打分引擎与 Playwright 自动化任务；
     - 提供候选人列表查询、单/批量批准发送、打分重算、配置读写等 RESTful 接口。
  2. **HR 待核验看板（轻量前端）**：
     - 卡片流布局展示待核验候选人（按分数降序）；
     - 直观呈现：**总分徽章、四维折算进度条、命中技术标签、AI提炼的3条核心亮点（绿）与1条潜在风险（橙）**；
     - 支持勾选候选人，点击“一键批准并发送打招呼”。
  3. **策略与参数热配置面板**：
     - 提供可视化滑块调整四维权重（如 40/30/20/10）及阈值（60/82）；
     - 提供配额修改表单（30/100）及开关切换（是否开启高分直发、是否自动点不合适）。
